### 更新方法

判断を追加する場合は既存の命名規約を優先し、規約がない場合は `YYYYMMDD-topic.md` とします。背景、判断、根拠・代替案、影響、再検討条件、関連資料を記録し、この一覧にリンクを追加します。未承認は Draft、承認後は承認者と実際の決定日を記録して Accepted に更新します。変更で置換する場合は旧記録を残し、Superseded と後続 ADR のリンクを記録します。
