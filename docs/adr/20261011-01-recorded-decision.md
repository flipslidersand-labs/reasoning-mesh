## 背景

README はローカル推論と任意の外部推論を共通のオーケストレーションで扱う。

## 記録する判断

README の推論 API を入口にタスクをルーティングし、Qdrant の知識を取得してモデル別アダプタへ渡す構成を記録する。

この ADR は既存資料・コードの判断を整理した遡及記録であり、今回の整備で新しい設計を承認・実装したものではない。設計資料にある将来案の実装完了は断定しない。

## 代替案と判断の根拠

上記の根拠資料に残る理由を記録する。比較した代替案・却下理由が資料にない場合は NEEDS_CONFIRMATION とし、後から選定経緯を作らない。

## 影響と制約

ルーティング方針、検索結果、モデルの失敗を分けて評価する必要がある。外部モデルを利用する場合はデータ送信範囲の確認が必要になる。

## 再検討する条件

モデル追加、ルーティング規則・検索コレクション変更。
